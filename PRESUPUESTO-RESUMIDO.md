# Presupuesto resumido — I Simposio sobre Memorias Participativas

## Tecnología

- **Framework**: Astro 7 + React 19 + Tailwind CSS 4
- **CMS**: Decap CMS + Netlify Identity
- **Backend**: 4 funciones serverless en Netlify
- **Hosting**: Netlify
- **Contenido**: Markdown en Git

## Costos de desarrollo

| Escenario | Horas | Costo estimado |
|---|---|---|
| Desarrollo desde cero | 216-332 h | €12.000 - €20.000 |
| Setup + despliegue (código ya listo) | 3-15 h | €800 - €1.500 |
| Despliegue básico (junior) | 3-5 h | €75 - €175 |

## Costos de hosting Netlify

| Plan | Mes | Año | Nota |
|---|---|---|---|
| **Free** | $0 | $0 | 300 créditos/mes, ~20 deploys. Límite estricto. |
| **Personal** | $9 | $108 | Recomendado si hay publicaciones frecuentes. |
| **Pro** | $20 | $240 | Para equipos con varios editores. |

Netlify Identity y Decap CMS están incluidos sin costo adicional.
